## 📂项目展示
### 项目一：灵山圣境 — AI智能导游小程序
> 技术栈：微信小程序 + 后端服务 + LLM大模型
- 项目简介：面向景区的AI导游小程序，基于用户实时定位，自动规划游览路线，沿路进行景点语音讲解。
- 核心功能
  1. 根据用户位置动态规划游览路线，自动推送景点讲解
  2. 实时检测用户是否偏离规划路线，发生偏离后交互确认是否继续讲解
  3. 支持视障人群友好路线规划，适配特殊出行需求
- 个人工作：完整参与前后端逻辑、定位逻辑、大模型对话交互、小程序端功能实现。

### 项目二：VisionForge AI 工业缺陷检测（视觉+机械臂具身项目）
> 技术栈：YOLOv11、Rust‑night、FastAPI、前端页面、ROS2仿真、总线舵机硬件
- 项目简介：工业工件视觉缺陷检测系统，结合视觉识别与机械臂执行单元，目标实现“视觉识别缺陷→机械臂执行对应动作”的完整具身闭环。
- 已完成内容
  1. 使用YOLOv11完成缺陷检测模型训练，摄像头实时画面推理检测工件缺陷
  2. 完成前端、后端整套服务，支持摄像头采集、推理结果展示
  3. ROS2完成七舵机机械臂仿真环境搭建
  4. 硬件：已采购单总线舵机、调试板、锂电池；可通过代码下发串口角度指令控制舵机转动
  5. 接入LLM Agent：大模型可以直接输出角度指令，下发控制舵机运动
- 待完成：剩余6个舵机采购后，完成实物七自由度机械臂整机联调，打通视觉检测到实体机械臂执行的完整链路。
